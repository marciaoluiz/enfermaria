# Enfermaria

Controle da enfermaria: estoque com validade, pacientes, atendimentos com CID-10, condutas e relatórios mensais.
Funciona no celular e no computador, sem internet. Os dados ficam só no aparelho (faça backup em Ajustes).

As relações de medicamentos de cada pista ficam em `relacoes/` (arquivos .json listados em `relacoes/indice.json`).
